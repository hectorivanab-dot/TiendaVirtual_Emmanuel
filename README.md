# Tienda Virtual en Consola

Proyecto desarrollado para la asignatura Programación de Software.

## Integrantes
- Hector Amado

## Descripción
Este proyecto consiste en una tienda virtual en consola desarrollada en Python usando Programación Orientada a Objetos (POO).

## Funcionalidades
- Ver catálogo de productos
- Agregar productos al carrito
- Calcular total de compra
- Manejo de usuarios
- Administración de inventario

## User Stories

### Cliente
Como cliente, quiero ver productos para elegir qué comprar.

### Cliente
Como cliente, quiero agregar productos al carrito para comprar varios artículos.

### Cliente
Como cliente, quiero ver el total de la compra para saber cuánto pagar.

### Administrador
Como administrador, quiero agregar productos para actualizar el inventario.
